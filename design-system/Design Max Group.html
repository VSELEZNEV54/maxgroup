Правила воспроизведения

Держим систему цельной. Смысловые ограничения важнее буквального копирования любого отдельного эффекта.

Сохранять

  • Inter Tight, двухтонные заголовки и табличные цифры
  • Холодный монохром, один главный синий акцент
  • Плоские плитки, тонкие линии, большие поля
  • Реальные изображения и проверенные факты
  • Короткую спокойную речь на «вы»

Исключить

  • Декоративные градиенты, свечение и стеклянные карточки
  • Падающие тени у обычных карточек
  • Случайные шрифты, капс и разрядку
  • Стоковые заглушки, эмодзи и смешанные иконки
  • Неподтвержденные цифры и рекламные обещания

Учитывать исключения

В работающем сайте есть затемняющие градиенты над фото, blur у верхних слоев и цветовые hover-переходы. Эти технические приемы не становятся декором презентации.

Соблюдать ритм

Для движения используются 160, 280, 560 и 900ms. Основная кривая cubic-bezier(0.16, 1, 0.3, 1). В презентации достаточно сдержанного появления.

Видимая русская проза сайта использует «е» вместо «ё», без тире и двоеточий. Служебная документация, код и адреса сохраняют необходимый синтаксис.

HTML помогает увидеть систему. Markdown объясняет правила. CSS и JSON дают точные значения для реализации.

Используй приложенный Design Max Group.md как текстовую спецификацию, HTML как визуальный образец, CSS и JSON как источник точных токенов. Сначала выдели главную мысль каждого слайда. Не выдумывай цены, сроки, рейтинги, отзывы, контакты и достижения компании.

Формат 16:9. Темная обложка с реальным фото Владивостока или автомобиля из переданных материалов. Дальше чередуй бумажные, белые и темные слайды по смыслу. Базовые цвета #0A0C0F, #F3F4F5, #FFFFFF. Единственный брендовый акцент #005DFA. На темном для синего текста используй #5C9BFF. Цвета статусов применяй только по смыслу.

Один шрифт Inter Tight. Текст 450, заголовки 500, выделения 600. Двухтонные заголовки с приглушенным продолжением, плотный интерлиньяж, легкий отрицательный трекинг. Без капса, декоративной разрядки и второго шрифта. Числа табличные.

Сетка для холста 1920×1080: поля 80-96px, 12 колонок, межколонник 24px. Это рекомендации для презентации. Заголовки 64-88px, на обложке 88-112px, основной текст 28-36px, подписи 22-24px. Не переноси веб-минимум 15px на слайды. В PowerPoint 13,333×7,5 дюйма этим значениям соответствуют примерно половинные числа в pt. Если редактор не поддерживает вес 450, выбери ближайший доступный и проверь композицию.

Одна мысль на слайд, от 2 до 4 фактов. Выравнивай по левому краю, оставляй воздух. Плитки плоские, радиус 4px, без падающих теней; зазор внутри плотной группы 8-12px. Тонкие разделители. Кнопки, если нужны по смыслу, пилюли; на темной обложке белая основная и контурная дополнительная.

Фото используй только из переданных материалов. Не рисуй новый логотип, не искажай пропорции существующего. Допустимы темные тональные маски поверх фото для читаемости. Без декоративных градиентов, стеклянных карточек, свечения, стоковых заглушек, эмодзи и произвольных 3D-иллюстраций. Иконки линейные 24×24, stroke 1.5, скругленные концы, из переданного набора.

Графики и таблицы делай плоскими, серии нейтральными, одну главную выделяй синим. Подписывай значения напрямую. Текст спокойный, конкретный, на «вы», без восклицаний и рекламных превосходных степеней. В видимой русской прозе используй «е» вместо «ё», избегай тире и двоеточий. Эти ограничения не распространяются на синтаксис кода и адреса.

Перед выдачей проверь читаемость, отсутствие обрезки, согласованность отступов, шрифта и цветов. Покажи итоговую структуру и отметь отсутствующие исходные данные отдельно от готовых слайдов.
