# Design Max Group

Дизайн-система текущего сайта «Макс Групп», версия 2. Снимок локального проекта от 12.11.2026.

## Как передать комплект

- `Design Max Group.html` — визуальный справочник. Открывается двойным кликом, работает без интернета, содержит встроенные шрифты и изображения.
- `Design Max Group.md` — эта спецификация, правила и готовый промпт для ИИ.
- `Design Max Group.css` — точные токены сайта, встроенные веб-шрифты и адаптированный набор компонентов `mg-*`.
- `Design Max Group.tokens.json` — все базовые токены, адаптивные переопределения, типографика, рекомендации для слайдов и контрольные суммы источников.
- `assets/` — логотипы для светлого и темного фона, три изображения из проекта и локальные WOFF2.
- `source/00-tokens.css` — исходный файл токенов без изменений. `source/logo-original.svg` — исходный SVG до цветовой обработки компонентом сайта.

Для знакомства достаточно HTML. Для генерации презентации передайте ИИ MD, HTML и содержание будущих слайдов. Для точного воспроизведения приложите CSS, JSON и нужные изображения. ZIP содержит весь комплект.

## 1. Суть

Макс Групп занимается автомобилями из Японии, Кореи и Китая под заказ. Визуальная концепция называется «Ночной порт». Темные кинематографичные планы Владивостока, дорог и автомобилей передают атмосферу. Светлые документальные полосы с цифрами, расчетами и тонкими линиями делают информацию ясной.

Характер — спокойный, точный, современный, сдержанный. Ощущение качества создают масштаб, типографика, фотография и пространство. Основные приемы:

1. Холодный монохром и один фирменный синий акцент.
2. Один шрифт Inter Tight и двухтонные заголовки.
3. Белый фон страниц. Серый отделяет карточки и поля. Фотографии, видео и подвал используют собственный фон.
4. Плоские почти прямоугольные плитки, плотные группы, кнопки-пилюли.
5. Крупные факты и тонкие разделители вместо украшений.
6. Реальные изображения проекта и сдержанное движение.

Источник системы — действующие `src/` и `assets/`. Архивные КП, планы и аналитические презентации не использовались как источник стиля. Правила ниже разделены на факты сайта и рекомендации для презентации. Это экспорт текущего состояния, а не новый фирменный стиль.

## 3. Типографика сайта

Одна гарнитура **Inter Tight**. Локальные WOFF2 поддерживают веса 400-700. Основные веса — 450 (текст), 500 (заголовки, кнопки), 600 (выделения). В отдельных strong может использоваться 700. Встроенные файлы — веб-шрифты; для редактора презентаций может потребоваться установленный desktop-шрифт той же гарнитуры. Если 450 недоступен, допускается ближайший доступный вес с визуальной проверкой. Это технический компромисс.

Стек `font-family`:

```css
'Inter Tight', 'Helvetica Neue', Arial, system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif;
```

`font-feature-settings: 'ss01', 'cv11'`. Для цифр `font-variant-numeric: tabular-nums`. Класс `.mono` в исходном проекте не меняет шрифт на моноширинный. Капс, капитель и декоративная разрядка отсутствуют.

--fs-mono: var(--fs-sm);
--fs-body: clamp(1rem, 0.9821rem + 0.0893vw, 1.125rem);

--fs-h3: clamp(1.3125rem, 1.1429rem + 0.8482vw, 2.5rem);
--fs-h2: clamp(1.75rem, 1.2rem + 2.75vw, 4.5rem);

Двухтонный заголовок объединяет основную мысль и контекст в одну строковую композицию. Например, «Авто под заказ» основным цветом, «из Азии» приглушенным. Не окрашивать произвольные слова ради декора. В стандартной шапке секции нет надзаголовка. Заголовок слева, пояснение справа на широком экране; на телефоне блоки идут друг под другом.

| Элемент | Правило |

| Карточка | Радиус 4px, внутренние поля `clamp(20px, 1.9vw, 28px)`, без падающей тени |
| Поле ввода | Радиус 10px, высота 56px, padding 18px, шрифт минимум 16px |
| Диалог | Радиус 16px, отдельный верхний слой |
| Кнопка / чип | Радиус 999px |
| Кнопка обычная | Высота минимум 48px, вес 500 |
| Кнопка маленькая | Минимум 44px |
| Кнопка большая | `clamp(56px, 3.25rem + 0.4vw, 64px)` |
| Фото автомобиля | Обычно 4:3, `object-fit: cover` |
| Фото команды | Обычно 4:5; формат зависит от конкретного блока |
| Иконка | Координатная сетка 24×24, линия 1.5, круглые концы и соединения |

Варианты кнопок — синяя, темная, белая, контурная. На текущем первом экране главная кнопка белая, вторая контурная. Состояния синей кнопки заданы отдельными токенами hover и press. На нажатии применяется `scale(.98)`. В горизонтальной кнопке оставляйте текст действия. Для вторичной ссылки «О компании» используйте одно подчеркивание. Стрелка нужна для направления движения в галерее, карусели или пагинации. Шеврон обозначает раскрытие списка. Для отдельной кнопки с иконкой укажите доступное название. У кнопок связи допустим значок мессенджера. Disabled получает opacity .55. Кольцо клавиатурного фокуса 2px с отступом 3px; на темном белое.

Карточки на paper белые; на белой секции светло-серые; на темной секции `--ink-2`. Контент разнесен по верху и низу. Строка фактов начинается с тонкой линии; значение крупнее пояснения. В таблице горизонтальные линии 1px, вторичная шапка, числовые значения выровнены вправо. Цвета ошибок сопровождаются текстом.

Тени допускаются у всплывающих слоев:

```css
--shadow-pop: 0 1px 2px rgba(10, 12, 15, 0.06), 0 12px 32px -8px rgba(10, 12, 15, 0.16);
--shadow-float: 0 2px 6px rgba(10, 12, 15, 0.08), 0 24px 64px -16px rgba(10, 12, 15, 0.28);
```

## 6. Логотип, фотографии и иконки

Исходная форма логотипа находится в `assets/img/brand/logo.svg`, пропорция `142:38`. На сайте компонент заменяет черный текст на `currentColor`, исходный цвет знака `#1F467F` на актуальный акцент `#005DFA`, а поверх темного фона делает знак белым. Для передачи подготовлены готовые `assets/logo-light.svg` и `assets/logo-dark.svg`. Старый цвет внутри оригинального SVG не является текущим акцентом интерфейса.

Сохранять пропорции логотипа. Не набирать его вручную другим шрифтом и не перерисовывать. Размер и охранное поле для презентаций отдельно не закреплены в исходном проекте; оставлять достаточный воздух — рекомендация, не существующий токен.

Использовать фотографии автомобилей, кейсов, команды, ночных дорог и Владивостока из проекта. В услугах уже есть предметные 3D-рендеры; это конкретные существующие материалы, а не разрешение добавлять произвольный 3D-стиль. Если изображения нет, решать композицию типографикой. Кроп не должен срезать главный объект.

В комплект включены `poster.webp` (реальный текущий hero), `bridge.webp` (ночная дорога) и `detail.webp` (деталь автомобиля). Темное затемнение поверх фото служит читаемости, не является декоративной цветной заливкой. Иконки берутся из единого набора `src/lib/icons.mjs`; соцсети и часть служебных иконок заливочные.

## 7. Движение и реализация исключений

Длительности `160 / 280 / 560 / 900ms` (`fast / base / slow / scene`). Основная кривая `cubic-bezier(0.16, 1, 0.3, 1)`. Дополнительные `ease-inout: cubic-bezier(0.65, 0, 0.35, 1)` и `ease-in: cubic-bezier(0.7, 0, 0.84, 0)`. Появление контента однократное, сдержанное. Учитывать `prefers-reduced-motion`.

Формулировки GUIDE описывают визуальный принцип, а CSS содержит технические исключения:

- Запрет градиентов относится к декоративным поверхностям. Тональные маски над фото/видео и маски краев прокрутки существуют.
- Запрет стекла относится к характеру карточек. Шапка, dock и некоторые верхние слои используют blur.
- Transform и opacity — основа появления. Hover также меняет цвет, рамку, фон; поля получают кольцо фокуса.
- Тени-рамки `inset`, кольца фокуса и локальные тени служебных контролов не равны падающим теням карточек.
- Один брендовый акцент не отменяет цвета состояний и локальные фирменные цвета иконок сервисов.

Не переносить технические исключения на всю презентацию. Достаточно простого появления или плавной смены слайда.

## 8. Тон текста

Спокойный и экспертный, обращение на «вы». Предложения обычно до 15-18 слов, абзацы 1-3 предложения. Сначала конкретный ответ, затем пояснение. Без восклицаний, канцелярита, превосходных степеней и неподтвержденных обещаний.

Видимая русская проза сайта использует «е» вместо «ё», без тире, двоеточий, капса и меток в квадратных скобках. Законные аббревиатуры и названия марок допустимы. В обычной фразе диапазон пишется «от 3 до 9», в факте или таблице «3-9». Синтаксис CSS/JSON, названия файлов и техническая документация сохраняют необходимые знаки.

В презентацию переносить только проверенные факты из предоставленного содержания. Образцы этого справочника показывают стиль и не содержат новых коммерческих обещаний.

## 9. Перенос в презентацию (рекомендации)

Следующие параметры разработаны для переноса стиля. В CSS сайта таких слайдовых токенов нет.

| Параметр | Холст 1920×1080 px | PowerPoint 13,333×7,5 дюйма |
|---|---|---|
| Формат | 16:9 | 16:9 |
| Поля | 80-96px | 40-48pt |
| Сетка | 12 колонок, межколонник 24px | межколонник 12pt |
| Заголовок | 64-88px | 32-44pt |
| Обложка | 88-112px | 44-56pt |
| Основной текст | 28-36px | 14-18pt |
| Подпись | 22-24px | 11-12pt |
| Крупный факт | 80-120px | 40-60pt |

Перевод в pt зависит от физического размера слайда. Таблица рассчитана для стандартного широкого PowerPoint около 13,333×7,5 дюйма (960×540pt), то есть половина чисел макета 1920×1080. Это не универсальная конверсия CSS px → pt. Для большого зала увеличить текст и сократить содержание; мелкие подписи оставлять только для второстепенного.

Радиусы и расстояния масштабировать пропорционально холсту. Внутри плотной группы плиток можно использовать 8-12px, между смысловыми блоками — 32-64px. Не делать интерфейсную кнопку обязательной частью статического слайда.

### Типы слайдов

1. **Обложка.** Реальное фото на весь холст с темной тональной маской, логотип, крупный двухтонный заголовок, короткое пояснение. Текст в безопасной зоне фото.
2. **Факты.** Paper-фон, заголовок слева, 2-4 крупные цифры или тезиса на тонких линиях. Много свободного места.
3. **Процесс.** Светлый или темный фон, 3-5 плоских плиток с номером, названием шага и одной короткой строкой. Последовательность понятна без сложной инфографики.
4. **Кейс.** Слева фото, справа название и 2-4 проверенных факта; подписи вторичным цветом. Без неподтвержденных оценок результата.
5. **Сравнение / расчет.** Светлая таблица или плоский график. Нейтральные серии, одна главная синяя, прямые подписи значений, без 3D и объемных теней.
6. **Разделитель / финал.** Темная база, один крупный тезис; контакты только если переданы и подтверждены. Можно использовать крупную контурную типографику как в футере сайта, если она не мешает содержанию.

Одна главная мысль на слайд. Чередование светлого и темного связано со структурой рассказа, не с механическим правилом через один слайд. Для графиков не придумывать отдельную радужную палитру. Цвет дополнять подписями.

### Контроль качества

- Inter Tight и согласованные веса на всех слайдах.
- Основная палитра совпадает с токенами, синий используется избирательно.
- Двухтонные заголовки читаются; вторичный текст не слишком бледный.
- Нет обрезанного текста, сиротских строк и случайных отступов.
- Нет декоративных градиентов, стекла, теней карточек, эмодзи и смешения наборов иконок.
- Изображения из проекта, логотип не искажен.
- Все бизнес-факты получены из содержания пользователя или подтвержденного источника проекта.

Сетка для холста 1920×1080: поля 80-96px, 12 колонок, межколонник 24px. Это рекомендации для презентации. Заголовки 64-88px, на обложке 88-112px, основной текст 28-36px, подписи 22-24px. Без декоративных градиентов, стеклянных карточек, свечения, стоковых заглушек, эмодзи и произвольных 3D-иллюстраций. Иконки линейные 24×24, stroke 1.5, скругленные концы, из переданного набора.

Графики и таблицы делай плоскими, серии нейтральными, одну главную выделяй синим. Подписывай значения напрямую. Текст спокойный, конкретный, на «вы», без восклицаний и рекламных превосходных степеней. В видимой русской прозе используй «е» вместо «ё», избегай тире и двоеточий. ## 11. Использование CSS

CSS автономный: шрифты встроены. Переменные `:root` совпадают с исходником. Компоненты `mg-*` — компактная адаптация для передачи, они не заменяют полный CSS работающего сайта. Основной контент нужно обернуть в `.mg-system`.

```html
<link rel="stylesheet" href="Design Max Group.css">
<main class="mg-system">
  <section class="mg-section">
    <div class="mg-container">
      <div class="mg-head">
        <h2>Авто под заказ <span class="mg-mute">из Азии</span></h2>
        <p class="mg-lead">Содержание из согласованного брифа</p>
      </div>
      <div class="mg-grid">
        <article class="mg-card">
          <h4>Название факта</h4>
          <p class="mg-muted">Подтвержденное пояснение</p>
        </article>
      </div>
    </div>
  </section>
</main>
```
